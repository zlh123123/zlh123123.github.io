Github Page更换新域名后如何更新配置

发表于2026-01-01|更新于2026-01-01|配置
|浏览量:

仓库界面操作

在仓库中和本地的CNAME文件中修改为新的域名；

在域名商操作都完成后，需要等一段时间（大致一小时）后在Setting中的Page项中做DNS校验，然后github会自动配置https服务，等着就行了。

域名商操作

在域名商的DNS解析服务中，添加如下项：

Type Name Value
A @ 185.199.108.153
A @ 185.199.109.153
A @ 185.199.110.153
A @ 185.199.111.153
CNAME www zlh123123.github.io
